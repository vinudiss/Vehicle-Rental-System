# 🚗 Vehicle Rental System 2.0

A comprehensive Java-based Vehicle Rental System for managing vehicle reservations, customers, payments, and administrative utilities. This project uses **Spring Boot**, **Hibernate (JPA)**, and follows a modular architecture.

---

## ✨ Features

- 👤 User registration and authentication
- 🚙 Vehicle listing and search
- 📅 Rental booking and confirmation
- 💳 Payment integration
- 🛠️ Admin dashboard for managing vehicles, rentals, and customers
- 🎨 Responsive web UI with modern design

---

## 🛠️ Technologies Used

| Technology | Description |
|------------|-------------|
| Java 17+ | Core programming language |
| Spring Boot | Backend framework |
| Hibernate (JPA) | ORM for database management |
| Maven | Build and dependency management |
| Thymeleaf | HTML templating engine |
| CSS & JavaScript | Frontend styling and interactivity |

## 🚀 Getting Started

### Prerequisites

- Java 17 or higher
- Maven 3.6+
- *(Optional)* MySQL or another supported database

### Build & Run

1. **Clone the repository:**
```bash
git clone https://github.com/vinudiss/Vehicle-Rental-System.git
cd Vehicle-Rental-System
```

2. **Build the project:**
```bash
mvn clean install
```

3. **Run the application:**
```bash
mvn spring-boot:run
```

4. **Access the app at:** http://localhost:8080
